Privacy policy

This personal setup accesses Drive file contents and metadata to synchronize files, including creating, updating, moving and deleting them.

Authorization credentials and local file copies are stored on the owner's devices. Remote files remain in Google Drive.

This website receives no Drive files, passwords or OAuth tokens. It has no forms or analytics. GitHub Pages may process ordinary website requests under its own privacy policy.

Google data is used only for synchronization and recovery. It is not sold, used for advertising or AI training, or shared with unrelated third parties. Its use follows Google's API Services User Data Policy, including Limited Use.

The owner controls file and backup retention and can revoke access through Google Account settings. Revoking access does not delete existing copies or backups.
